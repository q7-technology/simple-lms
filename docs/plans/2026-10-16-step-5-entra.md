# Simple LMS step 5: Entra sign-in — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build step 5 of `docs/plans/2026-10-12-simple-lms-design.md`: signing in with Microsoft Entra ID, in both apps, switched on and off like the other two ways in the **Sign-in** section of the desktop's **Settings** (already on `main`). A person's first Microsoft sign-in is matched to someone already in Simple LMS by their Entra object id, else by an email Microsoft has checked, and the object id is kept; someone Simple LMS doesn't know is told "Ask your manager to add you" and is never added. Usable end to end: an admin registers Simple LMS in the tenant, puts three values in `.env`, and Mel (a manager) and Kim (a learner) sign in with their work accounts on the desktop and on a phone; the admin signs in with Microsoft and switches passwords off, and `lms clear-setting sign_in_password` is the way back if it goes wrong.

**Architecture:** The same FastAPI app (`api/`, package `lms`). The API does OpenID Connect's authorisation code flow with PKCE itself, for both apps, which stay ordinary API clients (rule 4): `POST /v1/auth/entra/start` gives the app Microsoft's sign-in address, Microsoft sends the person back to `GET /v1/auth/entra/callback`, the API swaps the code for an ID token over its own connection, checks it, matches the person, and sends them to their app's sign-in page with a one-time hand-off code after the `#`; the app swaps that for a session with `POST /v1/auth/entra/finish`. A session token never goes in an address. Migration `0005` adds the `entra` session method and an `entra_sign_in` table for sign-ins under way. `lms/services/entra.py` holds the flow, the ID token check (PyJWT, by the tenant's published keys) and the matching; `lms/services/settings.py`, the one reader of settings, gains the `sign_in_entra` switch, whether Microsoft is set up, and a lock-out guard that now counts Microsoft. The desktop gains **Sign in with Microsoft**, a Microsoft box in **Settings → Sign-in** and **Unlink Microsoft** on a person (both in Game Mode's drawers over the classroom, and as pages with it off); the learner app gains **Sign in with Microsoft**. Tests use a Microsoft of their own (`api/tests/fake_entra.py`: a local signing key, its JWKS, signed test tokens, and a token endpoint that checks the secret and PKCE), so nothing goes over the network; the same file runs as a stand-in for the walkthrough.

**Tech Stack:** as before: Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2, Alembic, psycopg 3, pytest against a real PostgreSQL 16; Vite 6, React 19, TypeScript 5, Tailwind 4, Vitest 3 with Testing Library; Docker Compose, Caddy 2, GitHub Actions. One new dependency, pinned: `pyjwt[crypto]==2.15.1` (PyJWT with `cryptography`, for RS256). The two calls to Microsoft use the standard library's `urllib`; no OIDC client library.

### Decisions this plan makes that the design leaves open

- **The API does the whole OpenID Connect flow, for both apps: authorisation code with PKCE, a state and a nonce.** The client secret stays on the server, Microsoft talks to one redirect URI, and the apps stay ordinary API clients (rule 4) that never see an ID token. In three steps:
  1. `POST /v1/auth/entra/start` with `{ "app": "desktop" | "learner", "verifier" }`. `verifier` is a random secret the app makes and keeps in the tab's `sessionStorage`; the API keeps only its hash. The API makes a state, a nonce and a PKCE verifier, keeps them in an `entra_sign_in` row (the state as its hash), and answers Microsoft's authorise address, which the app opens (`window.location.assign`: a top-level navigation, so neither app's CSP changes).
  2. Microsoft sends the person to `GET /v1/auth/entra/callback?code=&state=`. The state is looked up, once, within 10 minutes; the code is swapped for an ID token over the API's own connection with the client secret and the PKCE verifier; the token is checked and the person matched. The API answers `303` to the app's sign-in page under the web address (`…/sign-in` or `…/learn/sign-in`) with `#entra=<hand-off code>`, or `#entra_error=not_matched | method_off | failed`, and `Cache-Control: no-store`. The fragment is never sent to a server or in a Referer; the access log leaves the callback's query string out, as it does a media link's.
  3. The app sends `POST /v1/auth/entra/finish` with the hand-off code and its verifier and gets a session, as from any sign-in, then takes the code out of the address bar and the history. A hand-off code works once, within 2 minutes, and only with the verifier of the tab that started it: a link to someone else's sign-in, or a planted one (login CSRF), signs nobody in. A wrong verifier uses the code up.
  Rows are cleared away a day on, when the next sign-in starts: they are not part of the training record.
- **One tenant, by its id.** `LMS_ENTRA_TENANT_ID` must be the Directory (tenant) ID, a GUID (`common`, `organizations` or a domain name refuse to start), and the client id a GUID. Microsoft's endpoints are fixed for a tenant (`https://login.microsoftonline.com/<tenant>/oauth2/v2.0/authorize`, `…/token`, `…/discovery/v2.0/keys`), so there is no discovery fetch. `LMS_ENTRA_AUTHORITY` (default `https://login.microsoftonline.com`) is there only to point at a stand-in. **These stay in `.env`, not on the Settings screen:** the client secret is a secret (the screen would have to be write-only for it, as for the email password, and a typo there could lock out every Microsoft account at once with no warning), and the tenant and client ids belong with it: all three come from one app registration and change together, rarely. Entra is offered only when all three are set and there is a web address (`public_url`, from Settings or `LMS_PUBLIC_URL`): `settings.entra_set_up()`. The redirect URI is that web address plus `/v1/auth/entra/callback`, never worked out from the request; changing the web address in Settings means changing it in Entra too, and the README says so.
- **The ID token is checked in full, though it came straight from Microsoft:** RS256 only (`none` and HS256 refused); signed by a key the tenant publishes (`kid`); issuer `<authority>/<tenant>/v2.0` exactly; audience the client id; `exp`, `nbf` and `iat` present and current with a minute's leeway; `nonce` the one sent; `tid` the configured tenant; `oid` present. Library: **PyJWT** (`pyjwt[crypto]==2.15.1`, pinned: it decides who is signed in, so a new version is a choice). The tenant's keys are fetched once and kept for a day, and fetched again at once when a token names a key not yet seen (Microsoft rolling its keys over); a token can only reach the check from Microsoft's own token endpoint, so that refetch can't be driven by anyone else. Nothing from Microsoft is kept but the object id: no access or refresh token, no Graph calls.
- **Matching, safely.** By `oid` (the Entra object id, which never changes and is never reused) when a person has one; else, the first time, by the `email` claim, but only when Microsoft says the tenant owns the email's domain (the optional claim `xms_edov`, which the README has the admin add). Never by `preferred_username`, a sign-in name rather than a checked email, and never by an email Microsoft hasn't verified: either could let someone take over a person whose email they can set. The first match keeps the `oid` on the person (`person.entra_oid`, unique since step 1); from then on the email doesn't matter. Refused, never added (`not_matched`, "Ask your manager to add you"): nobody matching; someone deactivated; someone whose record is already linked to a different Microsoft account. A manager can **Unlink Microsoft** on a person (`POST /v1/people/{code}/entra/unlink`, ending their Microsoft sessions) to put a wrong match right; `entra_linked` shows on the record.
- **An `entra` session** carries the person's own permission's scopes, as a password session does (a supervisor gets the matrix, an admin `*`). It ends after 12 hours idle, like a password session, and 12 hours after it began, however busy: Simple LMS hears nothing from Microsoft once someone is signed in, so an account closed there stops working here within a working day (and people who leave are deactivated, as always). The learner app sends `prompt=login`, so a shared tablet asks Microsoft for the password every time and never signs the next person in as the last; the desktop sends `prompt=select_account`. The desktop still turns a learner away to the learner app, however they signed in.
- **The switch** is a third sign-in setting, `sign_in_entra` (on by default, set here or default, no `.env` fallback, like the other two), in `Effective` and `Changes`; `GET /v1/settings` also answers its `"set_up"`, so the screen can say why the button isn't showing. `GET /v1/auth/methods` (new, no session) tells both sign-in pages what to offer, from `settings.offered()`: Microsoft only when it is on and set up. A way that is off is refused before anything else is looked at (`403 method_off`, as `main` already does for the other two, so a wrong PIN isn't counted), at `entra/start` and again at the callback and `entra/finish`. `auth.py`'s `_switched_on` and `_signed_in` lose their underscores, as the Microsoft routes use them too.
- **Nobody locks everyone out.** `admin_ways_in()` now counts Microsoft when it is on and set up, so `last_way_in` means password and Microsoft can't both be off (a PIN never opens the desktop). And an admin can't switch off the way their own session signed in (`409 own_method`, checked in `settings.save()`, which now takes the saver's sign-in method): so passwords go off only from a Microsoft session, which shows Microsoft works for an admin. A session already open when its way was switched off can still save other settings. If it goes wrong anyway (a client secret runs out with passwords off), `lms clear-setting sign_in_password` is the way back in; no command of this step's own, as that one already does it.
- **Caddy and Compose:** the callback is under `/v1/`, which Caddy already sends to the API; the apps reach Microsoft by a top-level navigation and the API reaches it directly, so both CSPs stay as they are. Compose gives the `api` service the `LMS_ENTRA_*` settings (not the worker, which never signs anyone in; `LMS_PUBLIC_URL` it has already).
- **Tests never touch the network.** `api/tests/fake_entra.py` makes an RSA key, publishes it as the tenant's JWKS, signs test ID tokens (good ones, and ones with the wrong issuer, audience, times, nonce, tenant, key or algorithm), and swaps a code for a token as Microsoft does, checking the client secret, the redirect URI and the PKCE verifier. The `entra` fixture puts it where `lms/services/entra.py` talks to Microsoft. Run on its own (`.venv/bin/python tests/fake_entra.py`), it is a stand-in sign-in page for the walkthrough when there is no tenant to hand.
- **Left for later, or out:** no people made from Entra and no permissions from Entra groups (the design: never created); one tenant only; no signing out of Microsoft on sign-out (the learner app's `prompt=login` covers a shared tablet); webhooks, API keys and the competency API (step 6).

```python
from __future__ import annotations

from datetime import datetime

from sqlalchemy import CheckConstraint, DateTime, ForeignKey, String, func
from sqlalchemy.orm import Mapped, mapped_column

from lms.models.base import Base


class EntraSignIn(Base):
    """One sign-in with Microsoft under way: sent to Microsoft with a state,
    a nonce and a PKCE challenge, back with a code, then handed to the app
    that started it by a one-time code only that app can use. Kept a day,
    then cleared away: it is not part of the training record."""

    __tablename__ = "entra_sign_in"
    __table_args__ = (
        CheckConstraint("app in ('desktop', 'learner')", name="app"),
        # a hand-off is for someone, and only once Microsoft has sent them back
        CheckConstraint("(person_id is null) = (handoff_hash is null)", name="handoff"),
        CheckConstraint("handoff_hash is null or returned_at is not null", name="returned"),
    )

    id: Mapped[int] = mapped_column(primary_key=True)
    # the state sent to Microsoft, which comes back in the address: its hash only
    state_hash: Mapped[str] = mapped_column(String(64), unique=True)
    # must come back inside the ID token, so a token meant for another sign-in is refused
    nonce: Mapped[str] = mapped_column(String(64))
    # PKCE: sent to Microsoft with the code, proving this API asked for it
    code_verifier: Mapped[str] = mapped_column(String(128))
    # desktop or learner: where the person goes back to
    app: Mapped[str] = mapped_column(String(8))
    # the hash of a secret the app keeps in the tab: only it can finish
    browser_hash: Mapped[str] = mapped_column(String(64))
    # cleared away a day on, by this index
    created_at: Mapped[datetime] = mapped_column(DateTime(timezone=True),
                                                 server_default=func.now(), index=True)
    returned_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True))
    person_id: Mapped[int | None] = mapped_column(ForeignKey("person.id"))
    handoff_hash: Mapped[str | None] = mapped_column(String(64), unique=True)
    finished_at: Mapped[datetime | None] = mapped_column(DateTime(timezone=True))
```

    return rsa.generate_private_key(public_exponent=65537, key_size=2048)


def _s256(verifier: str) -> str:
    return base64.urlsafe_b64encode(hashlib.sha256(verifier.encode()).digest()).rstrip(b"=").decode()


class FakeEntra:
    def __init__(self, tenant: str = TENANT, client: str = CLIENT, secret: str = SECRET,

        self.key, self.kid = new_key(), "key-1"

        self.codes: dict[str, dict[str, Any]] = {}

        them (None takes a claim out)."""

               "preferred_username": "someone@example.com.au", "iat": now, "nbf": now,
               "exp": now + 3600, "ver": "2.0"}

        if alg == "HS256":

        code = secrets.token_urlsafe(24)
        self.codes[code] = {"challenge": q["code_challenge"], "redirect_uri": q["redirect_uri"],
                            "token": token or self.sign(self.claims(nonce=q["nonce"], **claims))}
        return code, q["state"]

    # --- what Microsoft answers ---------------------------------------------

    def jwks(self) -> dict[str, Any]:
        jwk = json.loads(jwt.algorithms.RSAAlgorithm.to_jwk(self.key.public_key()))
        return {"keys": [{**jwk, "kid": self.kid, "use": "sig", "alg": "RS256"}]}

    def get(self, url: str) -> dict[str, Any]:
        assert url == f"{self.authority}/{self.tenant}/discovery/v2.0/keys", url
        self.key_fetches += 1
        return self.jwks()

    def post(self, url: str, data: dict[str, str]) -> dict[str, Any]:
        assert url == f"{self.authority}/{self.tenant}/oauth2/v2.0/token", url
        self.token_requests.append(data)
        given = self.codes.pop(data.get("code", ""), None)
        if data.get("client_id") != self.client or data.get("client_secret") != self.secret:
            return {"error": "invalid_client", "error_description": "AADSTS7000215: bad secret"}
        if given is None:
            return {"error": "invalid_grant", "error_description": "AADSTS70008: code expired"}
        if data.get("redirect_uri") != given["redirect_uri"]:
            return {"error": "invalid_grant", "error_description": "AADSTS50148: redirect_uri"}
        if _s256(data.get("code_verifier", "")) != given["challenge"]:
            return {"error": "invalid_grant", "error_description": "AADSTS501481: verifier"}

    from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

    base = f"/{fake.tenant}/"

    class Handler(BaseHTTPRequestHandler):
        def _send(self, status: int, body: str | dict, kind: str = "application/json",
                  headers: dict[str, str] | None = None):
            data = (json.dumps(body) if isinstance(body, dict) else body).encode()
            self.send_response(status)
            self.send_header("Content-Type", kind)
            self.send_header("Content-Length", str(len(data)))
            for k, v in (headers or {}).items():
                self.send_header(k, v)
            self.end_headers()
            self.wfile.write(data)

            path, _, query = self.path.partition("?")
            if path == base + "discovery/v2.0/keys":
                return self._send(200, fake.get(fake.authority + path))
            if path == base + "oauth2/v2.0/authorize":
                hidden = "".join(f'<input type="hidden" name="{html.escape(k)}" value="{html.escape(v)}">'
                                 for k, v in urllib.parse.parse_qsl(query))
                return self._send(200, PAGE.format(hidden=hidden, email="", oid=uuid.uuid4()),
                                  "text/html; charset=utf-8")
            self._send(404, {"error": "not_found"})

            form = dict(urllib.parse.parse_qsl(
                self.rfile.read(int(self.headers.get("Content-Length", 0))).decode()))
            if self.path == base + "oauth2/v2.0/token":
                answer = fake.post(fake.authority + self.path, form)
                return self._send(400 if "error" in answer else 200, answer)
            if self.path == base + "oauth2/v2.0/approve":

                    {"code": code, "state": state})
                return self._send(302, "", "text/plain", {"Location": back})
            self._send(404, {"error": "not_found"})

"""Signing in with Microsoft Entra ID: OpenID Connect's authorisation code
flow with PKCE, done by the API for both apps. Microsoft sends the person
back to the API with a code; the API swaps it for an ID token over its own
connection, checks the token (Microsoft's signature, by the tenant's
published keys; issuer, audience, times, nonce, tenant), and matches it to a
person. Nobody is ever created here: someone Simple LMS doesn't know is
refused. Only the ID token is used: no access token is kept or sent on."""
from __future__ import annotations

import base64
import hashlib
import hmac
import json
import logging
import threading
import time
import urllib.error
import urllib.parse
import urllib.request
from typing import Any

import jwt
from sqlalchemy import select
from sqlalchemy.orm import Session as Db

from lms.config import Settings
from lms.models import Person

log = logging.getLogger("lms.entra")

SCOPE = "openid profile email"
# a minute either way between Microsoft's clock and ours
LEEWAY = 60
# the tenant's signing keys, fetched again after a day, or at once when a
# token names a key we don't have (Microsoft has rolled them over)
KEYS_FOR = 24 * 3600
TIMEOUT = 10


class EntraError(Exception):
    """Microsoft's answer could not be used. The person is told only that
    signing in with Microsoft didn't work; the log says why."""


def issuer(s: Settings) -> str:
    return f"{s.entra_authority}/{s.entra_tenant_id}/v2.0"


def _endpoint(s: Settings, path: str) -> str:
    return f"{s.entra_authority}/{s.entra_tenant_id}/{path}"


def redirect_uri(public_url: str) -> str:
    """Registered in Entra as the app's Web redirect URI: under the web
    address in Settings (or LMS_PUBLIC_URL)."""
    return f"{public_url}/v1/auth/entra/callback"


def challenge(verifier: str) -> str:
    """PKCE's S256: the verifier's SHA-256, base64url without padding."""
    digest = hashlib.sha256(verifier.encode()).digest()
    return base64.urlsafe_b64encode(digest).rstrip(b"=").decode()


def authorise_url(s: Settings, public_url: str, *, state: str, nonce: str, verifier: str,
                  prompt: str) -> str:
    query = urllib.parse.urlencode({
        "client_id": s.entra_client_id,
        "response_type": "code",
        "redirect_uri": redirect_uri(public_url),
        "response_mode": "query",
        "scope": SCOPE,
        "state": state,
        "nonce": nonce,
        "code_challenge": challenge(verifier),
        "code_challenge_method": "S256",
        "prompt": prompt,
    })
    return f"{_endpoint(s, 'oauth2/v2.0/authorize')}?{query}"


# --- talking to Microsoft (tests put a stand-in here) --------------------------

def fetch_json(url: str) -> dict[str, Any]:
    with urllib.request.urlopen(url, timeout=TIMEOUT) as r:
        return json.load(r)


def post_form(url: str, data: dict[str, str]) -> dict[str, Any]:
    """Microsoft's JSON answer, an error ({"error", "error_description"}) as
    much as a token."""
    request = urllib.request.Request(url, data=urllib.parse.urlencode(data).encode(),
                                     headers={"Accept": "application/json"})
    try:
        with urllib.request.urlopen(request, timeout=TIMEOUT) as r:
            return json.load(r)
    except urllib.error.HTTPError as e:
        try:
            return json.load(e)
        except ValueError:
            return {"error": f"http_{e.code}"}


# --- the tenant's signing keys ---------------------------------------------------

class _Keys:
    def __init__(self):
        self.lock = threading.Lock()
        self.by_kid: dict[str, Any] = {}
        self.fetched_at: float | None = None


_keys = _Keys()
monotonic = time.monotonic


def forget_keys() -> None:
    """Fetch the keys afresh next time (the tests start each one clean)."""
    global _keys
    _keys = _Keys()


def _fetch_keys(s: Settings) -> dict[str, Any]:
    found = {}
    for jwk in fetch_json(_endpoint(s, "discovery/v2.0/keys")).get("keys", []):
        if jwk.get("kty") != "RSA" or jwk.get("use", "sig") != "sig" or "kid" not in jwk:
            continue
        try:
            found[jwk["kid"]] = jwt.PyJWK(jwk, algorithm="RS256").key
        except jwt.PyJWTError:
            continue
    return found


def signing_key(s: Settings, kid: str) -> Any:
    with _keys.lock:
        stale = _keys.fetched_at is None or monotonic() - _keys.fetched_at >= KEYS_FOR
        if stale or kid not in _keys.by_kid:
            try:
                _keys.by_kid = _fetch_keys(s)
            except (OSError, ValueError) as e:
                raise EntraError(f"could not fetch the tenant's signing keys: {e}") from e
            _keys.fetched_at = monotonic()
        key = _keys.by_kid.get(kid)
    if key is None:
        raise EntraError(f"the ID token is signed by a key the tenant doesn't publish: {kid}")
    return key


# --- the ID token ------------------------------------------------------------------

def check_id_token(s: Settings, token: str, nonce: str) -> dict[str, Any]:
    """The token's claims, once it is Microsoft's, for this app, from this
    tenant, current, and for this sign-in; EntraError otherwise."""
    try:
        header = jwt.get_unverified_header(token)
    except jwt.PyJWTError as e:
        raise EntraError(f"not an ID token: {e}") from e
    if header.get("alg") != "RS256":
        raise EntraError(f"an ID token signed with {header.get('alg')!r}, not RS256")
    key = signing_key(s, str(header.get("kid")))
    try:
        claims = jwt.decode(token, key, algorithms=["RS256"], audience=s.entra_client_id,
                            issuer=issuer(s), leeway=LEEWAY,
                            options={"require": ["exp", "nbf", "iat", "iss", "aud", "nonce",
                                                 "tid", "oid"]})
    except jwt.PyJWTError as e:
        raise EntraError(f"the ID token was refused: {e}") from e
    if not hmac.compare_digest(str(claims["nonce"]), nonce):
        raise EntraError("the ID token is for another sign-in (its nonce)")
    if claims["tid"] != s.entra_tenant_id:
        raise EntraError(f"the ID token is from another tenant: {claims['tid']}")
    return claims


def redeem(s: Settings, public_url: str, code: str, verifier: str,
           nonce: str) -> dict[str, Any]:
    """Swap Microsoft's code for an ID token, over the API's own connection,
    and check it."""
    try:
        answer = post_form(_endpoint(s, "oauth2/v2.0/token"), {
            "grant_type": "authorization_code",
            "client_id": s.entra_client_id,
            "client_secret": s.entra_client_secret,
            "code": code,
            "redirect_uri": redirect_uri(public_url),
            "code_verifier": verifier,
            "scope": SCOPE,
        })
    except (OSError, ValueError) as e:
        raise EntraError(f"could not reach Microsoft: {e}") from e
    if "id_token" not in answer:
        raise EntraError(f"Microsoft refused the code: {answer.get('error')}: "
                         f"{answer.get('error_description', '')}".strip())
    return check_id_token(s, answer["id_token"], nonce)


# --- who it is -------------------------------------------------------------------

def _verified_email(claims: dict[str, Any]) -> str | None:
    """The email claim, only when Microsoft says the tenant owns its domain
    (the optional claim xms_edov). preferred_username is never used: it is
    a sign-in name, not a checked email."""
    email = claims.get("email")
    if not isinstance(email, str) or claims.get("xms_edov") not in (True, 1, "1", "true"):
        return None
    return email.strip().lower() or None


def match(db: Db, claims: dict[str, Any]) -> Person | None:
    """The person this is: by their Entra object id once they have signed in
    with Microsoft before, else by a verified email, keeping the object id
    from then on. Nobody, or someone deactivated, is None: never created."""
    oid = str(claims["oid"])
    person = db.execute(select(Person).where(Person.entra_oid == oid)
                        .with_for_update()).scalar_one_or_none()
    if person is None:
        email = _verified_email(claims)
        if email is None:
            return None
        person = db.execute(select(Person).where(Person.email == email)
                            .with_for_update()).scalar_one_or_none()
        # someone already linked to another Microsoft account keeps it
        if person is None or person.entra_oid is not None:
            return None
        if person.active:
            person.entra_oid = oid
    return person if person.active else None

`api/lms/api/routes/entra.py`:
```python
"""Sign in with Microsoft, from either app, in three steps:

1. The app sends `POST /auth/entra/start` with a secret it keeps in the tab,
   and sends the person to the address it gets back: Microsoft's sign-in.
2. Microsoft sends them back to `GET /auth/entra/callback` with a code. The
   API swaps it for an ID token, checks it, matches the person, and sends
   them back to their app's sign-in page with a one-time hand-off code in
   the address's fragment (never sent to a server, nor in a Referer).
3. The app sends `POST /auth/entra/finish` with that code and its secret,
   and gets a session token, as from any other sign-in.

The session token never goes in an address. A hand-off code alone is no
use: only the tab that started the sign-in has the secret that goes with it,
so a link to someone else's sign-in signs nobody in."""
from __future__ import annotations

import hashlib
import hmac
import logging
import secrets
import urllib.parse
from datetime import UTC, datetime, timedelta
from typing import Literal

from fastapi import APIRouter
from fastapi.responses import RedirectResponse
from pydantic import BaseModel, ConfigDict, Field
from sqlalchemy import delete, select
from sqlalchemy.exc import IntegrityError

from lms.api.deps import DB
from lms.api.errors import Unauthorised
from lms.api.routes.auth import SessionOut, signed_in, switched_on
from lms.config import get_settings
from lms.models import EntraSignIn, Person
from lms.services import entra, settings

router = APIRouter(prefix="/auth/entra", tags=["auth"])
log = logging.getLogger("lms.entra")

# from start to Microsoft sending them back
STARTED_FOR = timedelta(minutes=10)
# from coming back to the app finishing
HANDED_FOR = timedelta(minutes=2)
# then the row is cleared away
KEPT_FOR = timedelta(days=1)
# a shared tablet asks for the password every time; a desktop lets them pick
PROMPT = {"learner": "login", "desktop": "select_account"}


class StartIn(BaseModel):
    model_config = ConfigDict(extra="forbid")
    app: Literal["desktop", "learner"]
    # a random secret the app keeps in the tab (sessionStorage) until it finishes
    verifier: str = Field(min_length=32, max_length=128, pattern=r"^[A-Za-z0-9_-]+$")


class StartOut(BaseModel):
    # Microsoft's sign-in page: the app sends the person there
    url: str


class FinishIn(BaseModel):
    model_config = ConfigDict(extra="forbid")
    code: str = Field(max_length=128)
    verifier: str = Field(max_length=128)


def _hash(raw: str) -> str:
    return hashlib.sha256(raw.encode()).hexdigest()


def _on() -> bool:
    """Switched on in Settings, and set up in .env."""
    return settings.offered(settings.current())["entra"]


def _must_be_on() -> None:
    switched_on(_on(), "Microsoft")


def _back(app: str, **fragment: str) -> RedirectResponse:
    """To the app's sign-in page, with what it needs after the #."""
    page = "/learn/sign-in" if app == "learner" else "/sign-in"
    url = f"{settings.current().public_url}{page}#{urllib.parse.urlencode(fragment)}"
    return RedirectResponse(url, status_code=303, headers={
        "Cache-Control": "no-store", "Referrer-Policy": "no-referrer"})


@router.post("/start", response_model=StartOut)
def start(body: StartIn, db: DB):
    """Where to send the person to sign in with Microsoft."""
    _must_be_on()
    now = datetime.now(UTC)
    db.execute(delete(EntraSignIn).where(EntraSignIn.created_at < now - KEPT_FOR))
    state, nonce = secrets.token_urlsafe(32), secrets.token_urlsafe(32)
    verifier = secrets.token_urlsafe(64)
    db.add(EntraSignIn(state_hash=_hash(state), nonce=nonce, code_verifier=verifier,
                       app=body.app, browser_hash=_hash(body.verifier), created_at=now))
    db.commit()
    return StartOut(url=entra.authorise_url(get_settings(), settings.current().public_url,
                                            state=state, nonce=nonce, verifier=verifier,
                                            prompt=PROMPT[body.app]))


@router.get("/callback", include_in_schema=False)
def callback(db: DB, state: str = "", code: str = "", error: str = "",
             error_description: str = ""):
    """Microsoft sends the person here. Always a redirect back to their app:
    `#entra=<hand-off code>`, or `#entra_error=` with not_matched (nobody
    here has that account), method_off, or failed (anything else)."""
    now = datetime.now(UTC)
    row = db.execute(select(EntraSignIn).where(
        EntraSignIn.state_hash == _hash(state), EntraSignIn.returned_at.is_(None),
        EntraSignIn.created_at > now - STARTED_FOR).with_for_update()).scalar_one_or_none()
    if row is None:
        # a state we never gave, or one used or too old: nobody to send back
        return _back("desktop", entra_error="failed")
    # each state comes back once, whatever happens next
    row.returned_at = now
    db.commit()
    if error or not code:
        log.info("Microsoft sign-in did not finish: %s %s", error, error_description[:200])
        return _back(row.app, entra_error="failed")
    if not _on():
        return _back(row.app, entra_error="method_off")
    try:
        claims = entra.redeem(get_settings(), settings.current().public_url, code,
                              row.code_verifier, row.nonce)
    except entra.EntraError as e:
        log.warning("Microsoft sign-in refused: %s", e)
        return _back(row.app, entra_error="failed")
    person = entra.match(db, claims)
    if person is None:
        db.rollback()
        log.info("Microsoft sign-in by someone Simple LMS doesn't know: oid %s", claims["oid"])
        return _back(row.app, entra_error="not_matched")
    handoff = secrets.token_urlsafe(32)
    row.person_id, row.handoff_hash = person.id, _hash(handoff)
    try:
        db.commit()
    except IntegrityError:
        # the same Microsoft account linked to someone else a moment ago
        db.rollback()
        return _back(row.app, entra_error="not_matched")
    return _back(row.app, entra=handoff)


@router.post("/finish", response_model=SessionOut)
def finish(body: FinishIn, db: DB):
    """A session for whoever Microsoft said it was. The hand-off code works
    once, for 2 minutes, with the secret its app started with."""
    _must_be_on()
    now = datetime.now(UTC)
    row = db.execute(select(EntraSignIn).where(
        EntraSignIn.handoff_hash == _hash(body.code), EntraSignIn.finished_at.is_(None))
        .with_for_update()).scalar_one_or_none()
    if row is None:
        raise Unauthorised("that Microsoft sign-in has finished or expired; try again")
    row.finished_at = now
    ok = (row.returned_at > now - HANDED_FOR
          and hmac.compare_digest(row.browser_hash, _hash(body.verifier)))
    person = db.get(Person, row.person_id)
    if not ok or person is None or not person.active:
        db.commit()
        raise Unauthorised("that Microsoft sign-in has finished or expired; try again")
    return signed_in(db, person, "entra")
```

import { useLoad } from "../lib/useLoad";
import { Problem } from "../ui/Drawer";
import { Logo } from "../ui/Logo";

/** What the API says when Microsoft sends someone back without a sign-in. */
const MICROSOFT_SAYS: Record<string, string> = {
  not_matched: "Nobody in Simple LMS has that Microsoft account. Ask your manager to add you.",
  method_off: "Signing in with Microsoft is switched off here.",
  failed: "Signing in with Microsoft didn't work. Try again.",
};
// until the API says, or if it can't: what every install starts with
const USUAL: SignInMethods = { pin: true, password: true, entra: false };

function refusal(e: unknown): string {
  if (e instanceof ApiError && e.code === "wrong_password") return "Wrong email or password.";
  if (e instanceof ApiError && e.code === "locked") return "Too many wrong passwords. Try again in 15 minutes.";
  if (e instanceof ApiError && e.code === "method_off") return /[.!?]$/.test(e.message) ? e.message : `${e.message}.`;
  if (e instanceof ApiError && e.status === 401) return "That Microsoft sign-in has finished or expired. Try again.";
  return (e as Error).message;
}

export function SignIn() {
  const { me, signIn, startEntra, finishEntra } = useAuth();
  const ways = useLoad(() => api.get<SignInMethods>("/v1/auth/methods"), []);
  const { hash } = useLocation();
  const navigate = useNavigate();
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  // the hand-off code being used, so it is sent once
  const handedOff = useRef<string | null>(null);

  // back from Microsoft: /sign-in#entra=<code>, or #entra_error=<why>
  useEffect(() => {
    const back = new URLSearchParams(hash.slice(1));
    const code = back.get("entra");
    const why = back.get("entra_error");
    if (!code && !why) return;
    // the code leaves the address bar and the history at once
    navigate("/sign-in", { replace: true });
    if (!code) {
      setError(MICROSOFT_SAYS[why!] ?? MICROSOFT_SAYS.failed);
      return;
    }
    if (handedOff.current === code) return;
    handedOff.current = code;
    setBusy(true);
    setError(null);
    finishEntra(code).catch((e) => setError(refusal(e))).finally(() => setBusy(false));
  }, [hash, navigate, finishEntra]);

  if (me) return <Navigate to="/" replace />;
  const on = ways.data ?? USUAL;

  async function submit(e: FormEvent) {
    e.preventDefault();
    setBusy(true);
    setError(null);
    try {
      await signIn(email.trim(), password);
    } catch (err) {
      setError(refusal(err));
      setPassword("");
    } finally {
      setBusy(false);
    }
  }

  async function microsoft() {
    setBusy(true);
    setError(null);
    try {
      await startEntra();
    } catch (err) {
      setError(refusal(err));
      setBusy(false);
    }
  }

  return (
    <main className="min-h-screen grid place-items-center p-6">
      <form onSubmit={submit} className="card w-full max-w-sm flex flex-col gap-4" style={{ boxShadow: "var(--shadow-lift)" }}>
        <div className="brand"><Logo />Simple LMS</div>
        <h1 className="m-0 text-2xl font-extrabold">Sign in</h1>
        {on.password && (
          <>
            <label className="label">Email
              <input className="field" type="email" autoComplete="username" value={email}
                     onChange={(e) => setEmail(e.target.value)} required />
            </label>
            <label className="label">Password

                     onChange={(e) => setPassword(e.target.value)} required />

        <Problem error={error} />

          <button type="button" className={on.password ? "btn" : "btn primary"} disabled={busy}

import { Navigate, useLocation, useNavigate } from "react-router-dom";

import type { SignInMethods } from "../api/types";
import { useSession } from "../auth/Session";
import { Logo } from "../ui";

/** What the API says when Microsoft sends someone back without a sign-in. */
const MICROSOFT_SAYS: Record<string, string> = {
  not_matched: "Nobody in Simple LMS has that Microsoft account. Ask your manager to add you.",
  method_off: "Signing in with Microsoft is switched off here.",
  failed: "Signing in with Microsoft didn't work. Try again.",
};
// until the API says, or if it can't: what every install starts with
const USUAL: SignInMethods = { pin: true, password: true, entra: false };

function refusal(e: unknown, withPassword: boolean): string {
  if (!(e instanceof ApiError)) return (e as Error).message;
  if (e.code === "wrong_pin") return "Wrong code or PIN.";
  if (e.code === "wrong_password") return "Wrong email or password.";
  if (e.code === "locked") return e.message.charAt(0).toUpperCase() + e.message.slice(1) + ".";
  if (e.code === "method_off") return /[.!?]$/.test(e.message) ? e.message : `${e.message}.`;
  // no reason given: still plain words, never "Simple LMS answered 401"
  if (e.status === 401) return withPassword ? "Wrong email or password." : "Wrong code or PIN.";
  if (e.status === 429) return "Too many tries. Wait a minute and try again.";
  if (e.status >= 500) return "Simple LMS couldn't sign you in just now. Try again in a minute.";
  return e.message;
}

/** Code and PIN first (a shared tablet, a phone); email and password for
 * those who have one; Microsoft when it is set up. Only the ways an admin
 * has left on. */
export function SignIn() {
  const { person, signInWithPin, signInWithPassword, startEntra, finishEntra } = useSession();
  const [on, setOn] = useState<SignInMethods>(USUAL);
  const [wantPassword, setWantPassword] = useState(false);
  const [who, setWho] = useState("");
  const [secret, setSecret] = useState("");
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  const { hash } = useLocation();
  const navigate = useNavigate();
  // the hand-off code being used, so it is sent once
  const handedOff = useRef<string | null>(null);

  useEffect(() => {
    let live = true;
    api.get<SignInMethods>("/v1/auth/methods").then((m) => { if (live) setOn(m); }, () => undefined);
    return () => { live = false; };
  }, []);

  // back from Microsoft: /learn/sign-in#entra=<code>, or #entra_error=<why>
  useEffect(() => {
    const back = new URLSearchParams(hash.slice(1));
    const code = back.get("entra");
    const why = back.get("entra_error");
    if (!code && !why) return;
    // the code leaves the address bar and the history at once
    navigate("/sign-in", { replace: true });
    if (!code) {
      setError(MICROSOFT_SAYS[why!] ?? MICROSOFT_SAYS.failed);
      return;
    }
    if (handedOff.current === code) return;
    handedOff.current = code;
    setBusy(true);
    setError(null);
    finishEntra(code).catch((e) => setError(e instanceof ApiError && e.status === 401
      ? "That Microsoft sign-in has finished or expired. Try again." : refusal(e, false)))
      .finally(() => setBusy(false));
  }, [hash, navigate, finishEntra]);

  if (person) return <Navigate to="/" replace />;
  // the PIN form first, unless PINs are off
  const withPassword = on.password && (wantPassword || !on.pin);
  const withPin = on.pin && !withPassword;

  async function submit(e: FormEvent) {
    e.preventDefault();
    setBusy(true);
    setError(null);
    try {
      if (withPassword) await signInWithPassword(who.trim(), secret);
      else await signInWithPin(who.trim(), secret);
    } catch (err) {
      setError(refusal(err, withPassword));
      setSecret("");
    } finally {
      setBusy(false);
    }
  }

  async function microsoft() {
    setBusy(true);
    setError(null);
    try {
      await startEntra();
    } catch (err) {
      setError(refusal(err, false));
      setBusy(false);
    }
  }

  function switchWay() {
    setWantPassword(!withPassword);
    setWho("");
    setSecret("");
    setError(null);
  }

  return (
    <main className="screen">
      <div className="top"><Logo />Simple LMS<span className="chip">My training</span></div>
      <h1 style={{ margin: "8px 0 0", fontSize: 28, fontWeight: 800 }}>Sign in</h1>
      {(withPassword || withPin) && (
        <form onSubmit={submit} style={{ display: "flex", flexDirection: "column", gap: 16 }}>
          {withPassword ? (
            <>
              <label className="label">Email
                <input className="input" type="email" autoComplete="username" value={who} onChange={(e) => setWho(e.target.value)} required />
              </label>
              <label className="label">Password
                <input className="input" type="password" autoComplete="current-password" value={secret}
                       onChange={(e) => setSecret(e.target.value)} required />
              </label>
            </>
          ) : (
            <>
              <label className="label">Your code
                {/* a shared tablet: nothing about the last person is saved or offered to the next */}
                <input className="input" autoComplete="off" autoCapitalize="characters" autoCorrect="off" spellCheck={false}
                       placeholder="e.g. LL042" value={who} onChange={(e) => setWho(e.target.value)} required />
              </label>
              <label className="label">PIN
                {/* browsers ignore "off" on a password field; "one-time-code" keeps the PIN out of saved passwords */}
                <input className="input" type="password" inputMode="numeric" autoComplete="one-time-code" maxLength={8}
                       value={secret} onChange={(e) => setSecret(e.target.value.replace(/\D/g, ""))} required />
              </label>
            </>
          )}
          {error && <div className="msg r" role="alert">{error}</div>}
          <button type="submit" className="big primary" disabled={busy || !who.trim() || (!withPassword && secret.length < 4)}>
            Sign in</button>
        </form>
      )}
      {!withPassword && !withPin && error && <div className="msg r" role="alert">{error}</div>}
      {on.pin && on.password && (
        <button type="button" className="link" onClick={switchWay}>
          {withPassword ? "Sign in with your code and PIN" : "Sign in with email and password"}</button>
      )}
      {on.entra && (
        <button type="button" className={withPassword || withPin ? "big" : "big primary"} disabled={busy}
                onClick={() => void microsoft()}>Sign in with Microsoft</button>
      )}
      {!on.pin && !on.password && !on.entra && (
        <p className="small">Signing in is switched off just now. Ask your manager.</p>
      )}
      {on.pin && (
        <p className="small" style={{ textAlign: "center", color: "var(--color-muted)", fontSize: 13, marginTop: "auto" }}>
          On a shared tablet you're signed out after 15 minutes without a tap. Forgotten your PIN? Ask your manager.
        </p>
      )}
    </main>
  );
}
